# VitaTheme v1.2.0

VitaTheme is now available for Windows x64 as an English setup wizard and a portable application. Both include the desktop runtime and work offline.

## Downloads

- **Setup:** `VitaTheme-1.2.0-Windows-x64-Setup.exe` — welcome screen, embedded MIT license, destination selection and installation.
- **Portable:** `VitaTheme-1.2.0-Windows-x64-Portable.exe` — run without installing. Recent projects and recovery use the local application data folder.
- **Checksums:** `SHA256SUMS.txt` — SHA-256 digests for both executables.

If the setup executable is already downloaded, no additional runtime or blockmap is needed. Release executables are unsigned.

## Changes

- Larger, centered LiveArea backgrounds in the editor.
- Shorter interface text and distinct fonts for headings, controls and technical details.
- Complete ATRAC9 container validation before importing music and when copying it for saving or export.
- Compatibility with AT9 loop metadata used by existing PS Vita themes.
- Automatic installation of a missing Electron development runtime when starting from source.
- Windows file-link tests adapted to the permissions available on the system.
- Tighter exclusions for private files, local photos, caches and generated release files.

## Validation

- Type checking, lint, formatting and all 62 test files pass on Windows: 1,177 tests passed and 24 skipped for platform or permission conditions.
- The Windows packaged application passes all 11 archive, integrity, privacy and Electron capability checks.
- The English setup wizard and Windows editor interface were reviewed.

## Current limitations

- Music must already be ATRAC9 `.at9`. MP3, WAV, FLAC and OGG encoding is not included.
- AT9 checks validate the container; they are not an antivirus scan or a guarantee that every encoded frame will play.
- The preview approximates the console interface. VitaTheme exports themes but does not install them on a PS Vita.
- Linux runtime testing remains pending. Automated package checks do not test installation or uninstallation.
